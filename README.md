# 🍋 Vyzhimalo — выжималка треков из плейлистов Яндекс Музыки

**Vyzhimalo** (от «выжимало») — консольная утилита, которая из любой публичной
ссылки на плейлист Яндекс Музыки выжимает аккуратный список треков:
«Авторы — Песня» или «Песня — Авторы», с временем или без, в TXT/CSV/JSON/Markdown/M3U.

```text
1.	Пример Артист - Придуманная Песня [3:21]
2.	Вторая Группа - Другой Трек [2:56]
3.	Третий Исполнитель - Новый Сингл [4:01]
4.	Четвёртый Артист - Свежий Релиз [2:47]
```

- **Ноль зависимостей** — только стандартная библиотека Python 3.9+
- **Без регистрации** — логин и токен Яндекса не нужны
- Оба формата ссылок: `/playlists/lk.xxx…` и `/users/<логин>/playlists/<номер>`
- По умолчанию выжимает повторы, помечает недоступные треки
- Хорошие ошибки: с подсказками, без стектрейсов

## Установка

```bash
# ничего устанавливать не надо — просто скачайте vyzhimalo.py
curl -LO https://raw.githubusercontent.com/deepkorochka/vyzhimalo/main/vyzhimalo.py
```

## Использование

```bash
python vyzhimalo.py <ссылка на плейлист> [опции]
```

| Опция | Значение |
| --- | --- |
| `-o, --output ФАЙЛ` | куда сохранить (по умолчанию `<название плейлиста>.<расширение>`) |
| `--format txt\|csv\|json\|md\|m3u` | формат вывода (по умолчанию `txt`) |
| `--order artist-title\|title-artist` | «Авторы - Песня» (по умолчанию) или «Песня - Авторы» |
| `--sep " — "` | разделитель (по умолчанию `" - "`) |
| `--no-duration` | убрать время трека `[3:57]` (по умолчанию показывается) |
| `--number` | нумеровать строки (по умолчанию нет) |
| `--album` / `--year` | добавить альбом / год релиза |
| `--link` | добавить ссылку на трек в Яндекс Музыке |
| `--keep-duplicates` | не удалять повторяющиеся треки |
| `--mark-unavailable` | помечать `[недоступен]` треки, которые выпили из сервиса |
| `--print` | вывести список в консоль, не писать файл |
| `--encoding` | кодировка файла (по умолчанию UTF-8 с BOM — Excel сразу открывает) |

Без аргументов запускается интерактивный режим — сам всё спросит.

### Примеры

```bash
# Просто выжать плейлист в «<Название плейлиста>.txt»
python vyzhimalo.py <ссылка на плейлист>

# «Песня — Авторы», без времени, с нумерацией, в консоль
python vyzhimalo.py <url> --order title-artist --no-duration --number --print

# CSV для Excel: альбом, год, ссылка
python vyzhimalo.py <url> --format csv -o vyzhato.csv

# Переслать другом в виде M3U-подобного плейлиста
python vyzhimalo.py <url> --format m3u -o chill.m3u
```

### Форматы вывода

- **txt** — заголовок + список строк «Авторы - Песня [время]»
- **csv** — таблица `#,авторы,песня,время,альбом,год,доступен,track_id,album_id,ссылка`
- **json** — полный массив треков со всеми полями
- **md** — markdown-список
- **m3u** — список `#EXTINF` + ссылка на трек (не для локального плеера — для удобочитаемости)

## Как это работает

Утилита ходит в публичное внутреннее API Яндекс Музыки (`api.music.yandex.net`)
без всяких токенов:

1. Для ссылок вида `/playlists/lk.ххх` сначала узнаёт владельца и «kind» плейлиста,
   затем запрашивает у `/users/<uid>/playlists/<kind>` полный список треков.
2. Для ссылок вида `/users/<логин>/playlists/<номер>` сразу второй шаг.
3. Если API прислал только ID, докидывает батчами `POST /tracks`.

Поддерживаются только **публичные** плейлисты. Приватные не читаются — так и
задумано: это чужая музыка. Инструмент неофициальный, к Яндексу отношения не
имеет. Скачиванием музыки он не занимается — только названия.

## Частые вопросы

**А потянет плейлист на 5000 треков?**
Да. Треки тоже качаются батчами по 100, есть retries и таймаут.

**Windows показывает кракозябры при `--print`?**
В cmd выполните `chcp 65001` перед запуском; файл всегда пишется в UTF-8.

**Это легально?**
Это неофициальный инструмент, читающий публичный каталог Яндекс Музыки тем же
способом, что и ваш браузер. Никаких личных данных он не передаёт; Яндексом не
поддерживается. Уважайте авторские права — здесь только названия, без
скачивания музыки.

### English summary

**Vyzhimalo** is a tiny dependency-free CLI that turns any public
Yandex Music playlist link into a neat track list (TXT/CSV/JSON/MD/M3U),
with configurable artist-title or title-artist order, durations, numbering,
albums, years and links. No login or tokens — it uses Yandex Music's public
internal API. Python 3.9+.
